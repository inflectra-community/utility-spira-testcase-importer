The Problem

Migrating test cases from external tools into Spira is painful:

  • Every customer has a different spreadsheet format
  • Column names and values don't match Spira's data model
  • Test steps are buried in rows or cells — need restructuring
  • Custom properties and list values vary per template
  • Excel Add-In requires exact formatting — manual Power Query

Result: hours of manual wrangling per customer. Error-prone. Unscalable.

The Solution

Heuristic-first, LLM-assisted importer:

  • Heuristics resolve 80%+ of mappings (zero cost, instant)
  • LLM handles only genuinely ambiguous columns
  • Human-in-the-loop approval before data touches Spira
  • Detects test step structure automatically
  • Resolves values to Spira IDs (priorities, statuses, custom lists)
